# 菜单拒绝接入重复失败保护

2026-10-11 12:02（北京时间）巡检发现，原生游戏会话归档中有98次
`!closeWindow`，其中97次实际工具回执为：

```text
Menu changed or closed. Query !window again before closing.
```

归档中最长连续95条助手调用都是关闭窗口。这是会话归档计数，没有逐条时间戳，
不能称作某个精确分钟内的95次调用，也不包含推测的服务器故障。

已有动作失败保护只识别可信动作边界的 `Action failed:` 或
`Action not started:`。菜单原语在前置条件不满足时返回普通字符串；菜单命令
又属于动作，因此既不进入查询重复保护，也不进入明确失败保护。无限响应循环
会把这些已发出的拒绝命令继续当成下一轮的理由。

## 改动与边界

`closeMenu` 与 `clickMenuSlot` 的实际前置拒绝统一加上 `Action not started:`。
过期窗口拒绝同时带请求编号和当前窗口编号；当前编号变化是新证据，会重置
现有比较。空槽、越界和占用光标也明确表示没有发起点击。没有扩大到任意服务器
或玩家文字的关键字判断，也没有增加模型请求、心跳、移动或公屏消息。

相同已验证模型命令、参数、完整明确拒绝和已测状态连续三次后提醒，第五次
通过现有任务控制器交回真实失败证据。正常点击和关闭路径不变，继续提示核查
光标与背包，不把提交关闭当成物品存取或任务成功。玩家显式操作、健康长动作、
更换任务、测量变化等原有重置与所有权边界保留。

这项修复尤其适用于共用本地推理服务：避免同一无效菜单命令反复占用游戏
决策请求。没有调整本地 Qwen 权重、上下文、思考、推理槽位或缓存参数，
没有测得对应线上请求的提速，不能给出延迟收益承诺。
