> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repair evidence-confirmed idle scheduling and repeated narration causes while preserving player interaction and ongoing work.

**Architecture:** Compare actual successive state revisions and correlate task, speech and playback ownership. Bound a measured futile protected-floor retreat, and classify real host tool receipts to quiet autonomous query preludes. Package N.E.K.O. changes using the existing companion series.

**Tech Stack:** Python asyncio/unittest, native observation WebSocket, N.E.K.O. plugin lifecycle, VoxCPM2 speech receipts.

**Spec:** User request of 2026-10-11: fix continued inactivity and several repeated spoken passages. This plan's constraints and acceptance scenarios are the implementation specification.

## Global Constraints

- Keep local Qwen/vision on RTX 3090, VoxCPM2 on RTX 3080 Ti and current thinking settings.
- Preserve incoming chat, private messages, gifts, server failures, permissions and abilities.
- Do not clear memories or suppress player interactions to hide repetition.
- Do not interrupt a healthy long-running action or treat a protected building as a server fault.
- Store diagnostic metadata only, without prompts, generated answers, voice IDs or credentials.

## Review Focus

- Foreign appearance epochs remain observable; do not change scheduling without reproducing that cause.
- Actual inventory progress, new danger and player messages must remain actionable.
- Repeated query replies must not become evidence of completed gameplay.
- Speech playback ownership and timeouts must be distinguished from duplicate generation.
- A successful inspection alone must not be reported as successful autonomous survival.
