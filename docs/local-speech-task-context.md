# 本地 Neko：语气控制隔离与任务上下文连续性

> 2026-10-12：输入摘要预算已按用户要求撤销；当前策略见[完整游戏上下文审计](complete-game-information.md)。本文保留原实验与历史证据。

## 回归报告 / Regression Report

用户报告读出 TTS 语气提示、突然说英文、重复旧任务，以及计划与行动脱节。
本次只修改配套 Neko 宿主和 Minecraft 插件，不更换模型、权重、显卡、
推理并发或 Minecraft 服务器配置。

### 证据与机理

- 本地适配器此前无条件把 `(语气描述)` 拼到合成正文，包括默认描述。
  括号并非独立控制通道。即使某些参考模式支持这种提示，也不能保证当前
  克隆与部署组合始终不朗读它；此前有限样本通过不等于持续可靠。
- 角色设置 API 实际为中文。联合回复协议只说“使用要求的语言”，收到的
  英文工具结果可能影响回复语言；这是待现场观察的解释，并非已证明的
  唯一成因。本次把实际会话 locale 明确写入稳定的表现协议。
- 插件把旧目标截到 180 字、结果截到前 240 字；下一轮又把目标截到
  32 字甚至 12 字。默认观察只留一个旧条目，压力大时删除旧结果。
  实际命令失败可能位于库存附录之后，因而消失。主脑每条通知还有
  1,000 token 的独立裁剪，单改插件不能解决整个链路。
- 修复前 35 秒连续观察共 19 帧，在线、生命/饥饿均 20，未见位移、动作
  或库存变化。另有真实商人返回没有铁锭换绿宝石的报价。开发期间已出现
  移动，不能把所有静止归因于同一个问题，也不能把无报价判成服务器故障。

### 修改后的行为

1. 本地 VoxCPM2 默认只合成干净台词。`voice_style_enabled` 只有显式
   `true` 才启用括号前缀；示例和本机部署设为 `false`。同次输出的表情、
   私有语气元数据、音色克隆、分句回执、中断和线上失败回退保留。
   语气自然语言前缀需独立听验后才能重新启用，不以 HTTP 200 验收。
2. 联合回复在请求副本中使用真实会话语言；英文游戏/工具数据不构成
   切换语言的请求。用户明确要求换语言仍优先，工具参数与玩家名保持原样。
   不改保存的历史，不增加翻译、表情分析或其他模型调用。
3. 最近 8 个已匹配任务保存完整接受目标和原始结果，带任务 ID、会话 ID
   和接收方式。正常终态工具结果也返回接受 ID、服务器回显 ID；旧协议
   FIFO 和本地超时明确区分，不伪造服务器匹配。
4. 决策视图保持完整目标，并提取对应收到的失败/结论。当前结果反馈最多
   240 token，历史反馈最多 180 token；原始附录仍通过完整观察查询。
   超过 900 token 的异常长目标整条转为 `taskOmitted/detailsRequired`，
   不用截断后的半句话替代已接受的指令。
5. 历史按完整“目标＋结果”成对选择，显示 `outcomesOmitted` 和查询入口。
   默认观察总预算为约 3,000 token，优先保留当前目标/失败和必要状态；
   历史可从 `minecraft_observe(detail="full",sections=[],max_events=0)`
   的 `recentTaskOutcomeDetails` 读取。超大原始响应仍有截断标记和分页。
6. 仅由宿主路由的 Minecraft `mc_keep_going/mc_completion` 主动通知使用
   2,400 token 单条预算；总回调上限仍为 3,000。判断使用来源、频道、
   消息种类等路由字段，游戏正文不能提升权限或预算。普通通知与被动
   观察仍使用原限制。事件合并、停止/忙碌/过期检查及任务独占不变。

这去除了有损的目标字符截断，同时保留去重、按需读取和资源保护。
最近回执不能代替长期任务知识；跨游戏会话仍清空，避免旧世界证据误用。
旁白不作为成功证据。说“准备去做”不等于工具已派发或服务器已完成。

### 验证

- 修复前：语气/语言 3 项失败；任务连续性 3 项失败；主脑接收链路
  2 项失败。均有本机日志。
- 修复后：Minecraft 插件 **236 项＋26 个子测试**通过；主脑、语音、
  locale、工具循环、回调所有权及中断相关 **920 项**通过。Ruff 与
  `git diff --check` 通过。
- 独立中文样本经真实本地 18041 合成，HTTP 输入没有语气描述，CPU ASR
  读回“你好呀 我现在准备出发 去完成今天的委托”，未读出控制文字。
  首 PCM 约 1.89 秒、完整合成约 7.55 秒、音频 3.52 秒。
  没有注入桌面、直播、公屏或 B 站。这仅验证本条内容，不能证明主观音色
  相似度、长期不漏读或播放卡顿已解决。
- Neko 源提交：语音/locale `bd35e55447867f6cfa3d1de9184838d6cece855b`；
  任务连续性 `02c325c228bc85fedf8d31b6c049bda2de4fa44e`。
  配套补丁按 manifest 顺序应用并核对全部 SHA-256 和最终 tree/blob。

### 风险与运行验收

更完整的动态结果会多用部分输入 token；这是恢复关键证据的取舍，不能
直接宣称每轮更快。固定提示、模型设置、缓存、事件调度和无新增调用保持。
极端长历史仍需按需读取，任务策略也可能选错前置条件。当前仍有播放
结束看门狗超时证据，语音连续性、自然交易/委托结算和战斗验收保持开放。
